■ ブルアカ漢字クイズ - 遊び方 (README)

【基本ルール】
画面に表示される漢字の読み仮名を
キーボードで入力してください。

ローマ字（例: sunaookami）または ひらがな（例: すなおおかみ）の
どちらを入力してもリアルタイムに自動判定されます。

【制限時間とスコア】
・制限時間: 1問につき12秒です。
・基本得点: 難易度(Lv.1〜5) × 200 + 800 点
・タイムボーナス: 残り秒数に応じてボーナス加算
・コンボボーナス: 連続正解数に応じて追加点加算
※ミスするとコンボはリセットされます。

【🏆 ランク評価基準】
・プラチナ : 全問正解（パーフェクト） かつ 平均回答速度2.5秒以下
・ゴールド     : 全問正解（パーフェクト） かつ 平均回答速度3.5秒以下
・シルバー   : 1問以上ミスあり かつ 平均回答速度5.0秒以下
・ブロンズ   : 上記以外（平均回答速度5.0秒超など）
